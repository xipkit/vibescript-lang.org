 Language

    
If you know Ruby, much of this will look familiar.

    
Write functions, work with collections, and check types before running. Vibescript also has money, durations, and enums built in.

  


  

    

      
Small on purpose.

      

        Functions have names, and blocks run during the call that receives them.
        Changing an array or hash leaves other copies alone. Hash keys are strings,
        and records declare the keys they contain.
      

    

    

      

        

          small_surface.vibe
        

        
module Scoring
  BONUS = 10

  def self.with_bonus(score: int) -> int
    score + BONUS
  end
end

type Order = { status: string }

def approve(order: Order) -> { original: Order, updated: Order, same_key: bool, score: int }
  original = order
  order["status"] = "approved"

  { original: original, updated: order,
    same_key: order["status"] == order["status"],
    score: Scoring.with_bonus(80) }
end

Set hard limits for each script.

      

        Set a budget for execution steps, memory, and call depth. If a script reaches
        a limit, the engine stops it and returns an error.
      

    

    

      

        

          untrusted.vibe · sandboxed
        

        
$ cat untrusted.vibe
def run
  balance = 0
  while true
    balance = balance + 1
  end
end

$ vibes run --function run untrusted.vibe
RuntimeError: step quota exceeded
✓ stopped at 1,000,000, page stays responsive

      

    

  


  

    

      
Built-in money, duration, and enum types.

      

        Write 3.days for a duration. Use money values for exact decimal
        arithmetic. Define enums for choices such as shipping speeds or order states.
      

    

    

      

        

          primitives.vibe
        

        
enum ShippingSpeed
  Economy
  Priority
  Overnight
end

def transit_time(speed: ShippingSpeed) -> duration
  if speed == ShippingSpeed::Overnight
    6.hours
  else
    5.days
  end
end

def net_after_fee(cents: int) -> money
  gross = money_cents(cents, "USD")
  gross - money("1.75 USD")
end

Sandbox limits

    
These limits apply to this site's examples. Choose the values that fit your app.

    

      

        
 Step quota 1,000,000

        
Stops execution when the script uses its step budget.

      

      

        
 Recursion limit 128

        
Limits how deeply function calls can nest.

      

      

        
 Memory quota 16 MiB

        
Limits the memory a script can use.

      

      

        
 Effects control strict

        
Operations such as database writes need permission from your app.

      

      

        
 Module paths allowlist

        
Loads modules from directories you approve.

      

      

        
 App access host adapters

        
You choose which services scripts can call.
